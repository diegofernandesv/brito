# esbritoo — portfolio

Next.js + GSAP portfolio for Gabriel Brito.

```bash
npm install
npm run dev
```

- Edit text, videos and photos in `lib/content.ts`.
- Put your own clips in `public/videos/` and reference them as `/videos/my-clip.mp4`.
- Photos: add `poster: "/images/photo.jpg"` to items in `photos`.
